Sebelum upload

  • API key Open Cloud aktif
  • Izin asset:write
  • Creator User ID atau Group ID yang benar

Assets API saat ini berstatus beta. Batas Roblox mencakup file maksimal 20 MB; dashboard ini membatasi 4.5 MB agar sesuai batas request Netlify Functions.
